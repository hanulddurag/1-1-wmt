스프레드시트의 Apps Script를 웹 앱으로 배포하여 생성된 URL을 연동 설정에 등록하시면, 학생들의 성적이 [시트 1], [시트 2], [시트 3] 탭으로 자동 분류되어 수집됩니다.

구글 스프레드시트로 답안을 연동하는 중입니다...

제출 시, 자동으로 채점이 이루어지며 결과가 구글 스프레드시트의 해당 시트로 전송됩니다.

📊 스프레드시트 Apps Script 연동 설정

구글 스프레드시트의 [확장 프로그램] ➡️ [Apps Script]를 통해 얻은 웹 앱 배포 주소를 입력하여, 설문지 껍데기 없이 직접 스프레드시트 데이터베이스로 연결합니다.

초간단 시트 연결 가이드

  1. 구글 스프레드시트를 열고 하단 탭 이름을 시트 1, 시트 2, 시트 3으로 만듭니다.
  2. 확장 프로그램의 Apps Script 창을 열어 Code.gs의 수신 코드를 붙여넣고 저장합니다.
  3. 우측 상단 [배포] ➡️ [새 배포]를 누르고 유형을 웹 앱으로 지정한 뒤 액세스 대상을 '모든 사람'으로 배포하여 주소를 발급받습니다.
  4. 발급받은 웹 앱 배포 주소(https://script.google.com/...)를 아래에 입력하고 저장합니다.
